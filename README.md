# 🏥 Hospital Emergency Room Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing hospital emergency room operations using Microsoft Excel. The dashboard provides insights into patient admissions, waiting times, patient satisfaction, demographics, attendance status, and department referrals.

The objective is to transform hospital data into meaningful insights that can help understand operational performance and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze the total number of patients visiting the emergency room.
- Monitor average patient waiting time.
- Evaluate patient satisfaction scores.
- Understand admission and attendance patterns.
- Analyze patient demographics by age group and gender.
- Examine department referral patterns.
- Track daily trends in patient visits, waiting times, and satisfaction.

## 🔍 Analysis Performed

### 1. Patient Admission Analysis
- Analyzed admitted and non-admitted patients.
- Compared admission distribution.
- Identified the proportion of patients admitted.

### 2. Patient Demographic Analysis
- Analyzed patient distribution by gender.
- Examined patient distribution across different age groups.

### 3. Department Referral Analysis
- Examined patient referrals across different hospital departments.
- Identified departments with higher referral volumes.
- Investigated records without a specified department referral.

### 4. Patient Attendance Analysis
- Compared patients who were attended on time and those who experienced delays.

### 5. Daily Trend Analysis
- Analyzed daily patient visit trends.
- Monitored changes in average waiting times.
- Evaluated daily patient satisfaction trends.
